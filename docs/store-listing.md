# Chrome 웹 스토어 등록 메모 (Unlisted)

## 올리는 순서

1. https://chrome.google.com/webstore/devconsole 에서 개발자 등록(1회 5달러, 2단계 인증 필요)
2. `npm test` 통과 확인 후 `npm run package:store` → `dist/toytype-<version>.zip`
3. 대시보드 [새 항목] → zip 업로드. 이때 스토어 확장 ID가 발급된다.
3-1. `PRIVACY.md`가 GitHub main에 올라가 있어야 방침 URL이 열린다(커밋·푸시).
4. 발급된 ID를 `tools/install_native_host.mjs`의 `STORE_EXTENSION_ID`에 넣고 커밋한다.
   스토어판에서 브리지를 쓰는 사람은 `npm run setup`을 다시 돌려야 한다.
5. 아래 문구로 [스토어 등록정보]·[개인정보 보호] 탭을 채운다.
6. [배포] 탭에서 공개 범위를 **미등록(Unlisted)** 으로 고르고 심사 제출.
7. 승인 후 스토어 링크를 아는 사람만 설치할 수 있다. 검색에는 안 나온다.

업데이트할 때는 `manifest.json`의 `version`을 올리고 다시 패키징해 같은 항목에 업로드한다.

## 스토어 등록정보

- **이름**: 토인비 편집
- **카테고리**: 도구 (Tools)
- **언어**: 한국어
- **요약(132자 이내)**: 웹페이지와 Google Docs 원고의 오탈자·띄어쓰기·용어 혼용을 내장 규칙으로 찾아 주는 IT 원고 교정 도우미
- **설명**:

  ```
  토인비 편집은 IT 도서 원고 편집을 위한 교정 도우미입니다.

  • 내장 규칙 약 6,800개로 표기 변환, 맞춤법, 존대·복수, 높임말 서술어, 띄어쓰기를 검사합니다.
  • 일반 웹페이지: 발견 위치에 물결 밑줄을 표시합니다(페이지 구조는 바꾸지 않음).
  • Google Docs: 우하단 패널에서 항목을 누르면 문서의 해당 위치로 이동하고, [적용]을 누를 때만 교정어로 바꿉니다.
  • 용어 통일 표: 같은 용어가 여러 표기로 섞여 쓰인 곳을 형태소 분석으로 찾아 표로 보여 줍니다.
  • HWPX 내보내기, 이미지·목차 추출, 단락 스타일 셋팅.
  • (선택) 로컬 브리지를 따로 설치하면 AI 교정·사실 검증·문장 길이 조절·도해 기능을 쓸 수 있습니다. 기본은 꺼져 있습니다.

  기본 검사는 모두 브라우저 안에서 이루어지며, 문서 내용을 외부로 보내지 않습니다.
  ```

- **스크린샷**: 1280×800 PNG 1~5장 (Docs 패널 목록, 용어 통일 표, 일반 페이지 밑줄)
- **아이콘**: `icons/icon-128.png`
- **작은 프로모션 타일**: `docs/store/promo-tile-440x280.png` (원본 `docs/store/promo-tile.html`, 헤드리스 Chrome으로 다시 렌더링 가능)

## 개인정보 보호 탭

- **단일 목적**: 웹페이지와 Google Docs 원고의 오탈자·표기 오류 후보를 찾아 보여 주고, 사용자가 고르면 교정어로 바꾼다.
- **개인정보처리방침 URL**: https://github.com/startedourmission/Toytype/blob/main/PRIVACY.md
- **원격 코드 사용**: 아니요 (모든 스크립트와 wasm은 패키지에 포함)
- **수집 데이터 신고**: "웹사이트 콘텐츠" — 오탈자 검사를 위해 페이지 텍스트를 읽지만 브라우저 안에서만 처리하고 전송하지 않는다. 판매·제3자 제공·무관한 용도 사용 없음에 모두 체크.

### 권한별 사유

| 권한 | 사유 |
|---|---|
| `storage` | 검사 카테고리·사이트별 끄기 설정, 문서별 숨김 항목과 결과 캐시 저장 |
| `activeTab` | 툴바 팝업에서 현재 탭의 검사 결과를 보여 주고 다시 검사 |
| `nativeMessaging` | 사용자가 AI 기능을 켠 경우에만, 직접 설치한 로컬 브리지 프로그램을 [연결] 버튼으로 시작 |
| `clipboardRead` | [AI 도해] 실행 시 Google Docs 선택 영역의 그림·그리기 데이터를 복사해 읽기 |
| `clipboardWrite` | 항목을 누르면 교정어·도해를 클립보드에 복사 |
| 호스트 `docs.google.com` | Google Docs 원고 본문을 읽어 검사하고 패널 표시 |
| 호스트 `*.googleusercontent.com` | Docs 문서 안 이미지 추출·HWPX 내보내기 시 이미지 파일 받기 |
| 호스트 `127.0.0.1`, `localhost` | 사용자 컴퓨터에서 실행 중인 로컬 브리지와 통신(선택 기능) |
| 콘텐츠 스크립트 `<all_urls>` | 모든 웹페이지 본문의 오탈자 검사가 핵심 기능. 사이트별로 끌 수 있음 |

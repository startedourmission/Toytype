# 토인비 편집 (Toytype)

웹페이지와 Google Docs 원고의 오탈자를 찾아 주는 Chrome 확장 프로그램입니다.
Google Drive에서는 쪽수 세기, 이미지·목차 추출, 폴더 미리보기, 여러 문서를 격자로 띄워 AI 에이전트와 함께 고치는 격자 보기를 씁니다.

## 설치

### 1. 확장 프로그램 넣기 (누구나)

1. 이 저장소를 내려받아 원하는 곳에 둡니다. (GitHub에서 [Code] → [Download ZIP]으로 받았다면 압축을 풉니다.)
2. Chrome 주소창에 `chrome://extensions`를 입력해 엽니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드**를 누르고, 내려받은 `Toytype` 폴더를 고릅니다.
5. 주소창 오른쪽의 퍼즐 아이콘을 눌러 토인비 편집 옆 핀을 꽂아 두면 툴바에 항상 보입니다.

여기까지만 해도 오탈자 검사, 쪽수 세기, 이미지·목차 추출을 바로 쓸 수 있습니다.
이미 열려 있던 Google Docs·Drive 탭은 한 번 새로고침(⌘R)해야 확장이 붙습니다.

### 2. AI 기능 켜기 (선택)

AI 교정, 사실 검증, 격자 보기의 에이전트 같은 AI 기능은 내 컴퓨터의 AI 프로그램을 빌려 씁니다. 처음 한 번만 준비하면 됩니다.

1. **Node.js 설치** — [nodejs.org](https://nodejs.org)에서 LTS 버전을 받아 설치합니다. 터미널에서 `node -v`를 쳐서 버전이 나오면 됩니다.
2. **AI 프로그램 하나 설치·로그인** — Codex(`codex`), Claude Code(`claude`), Grok(`grok`) 중 하나를 설치하고 로그인해 둡니다. 각 서비스 구독이 필요합니다.
3. **연결 프로그램 등록** — 터미널을 열고 `Toytype` 폴더로 이동해 아래 명령을 한 번 실행합니다.

   ```bash
   cd 내려받은/경로/Toytype
   npm run setup
   ```

4. 툴바의 토인비 편집 아이콘을 눌러 **브릿지 · AI 기능 사용**을 켜고, **AI 엔진**에서 설치한 프로그램을 고른 뒤 **테스트**를 누릅니다. 초록색으로 연결되면 끝입니다.

이후로는 컴퓨터를 켤 때마다 연결 프로그램이 알아서 실행됩니다. 터미널을 다시 열 필요가 없습니다.
등록을 지우려면 `npm run setup:remove`를 실행합니다.

### 잘 안 될 때

- **버블이 안 보이거나 버튼이 반응하지 않음** — 확장을 새로 넣었거나 다시 불러온 뒤에는 열려 있던 Docs·Drive 탭을 새로고침(⌘R)합니다.
- **AI 연결이 [꺼짐]으로 나옴 · 코드를 받은 뒤 새 기능이 안 먹힘** — `Toytype` 폴더에서 `npm run bridge:restart`를 실행합니다. 상주 브리지를 새 코드로 다시 띄웁니다(터미널은 닫아도 됩니다). 상태는 `npm run bridge:status`, 로그는 `~/.toytype/logs/bridge.log`에 있습니다.
- **Safari** — Safari는 위 3번 등록을 쓰지 못합니다. `Toytype` 폴더에서 `npm run bridge:restart`를 한 번 실행하세요.
